# Paradigm Services & Installations — Marketing Site

A production-ready marketing site for **Paradigm Services and Installations LTD**, a plumbing, gas, drain, and electrical contractor serving Metro Vancouver. Replaces the existing Elementor/WordPress site at https://paradigmservices.ca/.

## Stack

- **Framework**: Next.js 15 (App Router) + TypeScript
- **Styling**: Tailwind CSS v4 (CSS-variable design tokens, light/dark)
- **Animation**: [Anime.js v4](https://animejs.com/) — scroll reveals, parallax, marker pulse, testimonial carousel
- **Icons**: lucide-react
- **Forms**: React Hook Form + Zod
- **Theme**: next-themes (light / dark / system)
- **Node**: 20.x

## Run locally

```bash
npm install
npm run dev          # http://localhost:3000
```

## Build & serve

```bash
npm run build        # produces .next/
npm start            # serves the production build on :3000
```

## Deploy to Vercel

1. Push this directory to a Git repo (GitHub / GitLab / Bitbucket).
2. In Vercel, **New Project → Import**, pick the repo.
3. Framework preset: **Next.js**. Build command and output directory default.
4. (Optional) set env vars in **Project Settings → Environment Variables**:
   - `RESEND_API_KEY` — once you wire `/api/contact` to Resend.
5. Deploy.

No `vercel.json` is required — defaults are correct.

## What was built

- All routes listed in the spec (home, about, services index, 6 service details, contact, tips, 404)
- Light + dark themes (next-themes)
- Brand color tokens as CSS variables (`--brand-blue-*`, `--brand-orange*`)
- Anime.js v4 scroll reveals, parallax (0.2 / 0.5 / 1.0), staggered grids, map marker pulse, testimonial carousel
- `prefers-reduced-motion` respected globally
- Sticky header with mobile drawer + theme toggle
- Accessible focus rings, semantic HTML, descriptive alt text
- Per-page metadata + dynamic OG image (`/opengraph-image`)
- JSON-LD `LocalBusiness` schema on the home page
- Sitemap + robots.txt via Next 15's `app/sitemap.ts` and `app/robots.ts`
- Contact form (React Hook Form + Zod) wired to `/api/contact` (stub)

## Wire the form to email

Currently `src/app/api/contact/route.ts` validates and `console.log`s the submission. For production:

1. `npm i resend`
2. Add `RESEND_API_KEY=...` to `.env.local` (and Vercel envs)
3. Replace the `console.log` block in the route with:

   ```ts
   import { Resend } from "resend";
   const resend = new Resend(process.env.RESEND_API_KEY!);
   await resend.emails.send({
     from: "Paradigm Site <site@paradigmservices.ca>",
     to: "info@paradigmplumbinggas.com",
     subject: parsed.data.emergency
       ? `[EMERGENCY] ${parsed.data.service}`
       : `New estimate request: ${parsed.data.service}`,
     replyTo: parsed.data.email,
     text: `From: ${parsed.data.name} <${parsed.data.email}> (${parsed.data.phone})\n\n${parsed.data.message}`,
   });
   ```

Alternative no-code options: [Formspree](https://formspree.io/), [Web3Forms](https://web3forms.com/) — point the form action there and skip the API route.
