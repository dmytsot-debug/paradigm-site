# Image assets

This site currently renders placeholder visuals (CSS gradients, SVG illustrations) so it can run without binary assets. Replace each placeholder before launch.

| File path                       | Used in                                            | Source on the existing WordPress site                                                       |
| ------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `/public/images/truck.png`      | Hero mid layer — replace `TruckPlaceholder` in `src/components/sections/Hero.tsx` | `https://paradigmservices.ca/wp-content/uploads/2026/05/clean-branded-truck.png`            |
| `/public/images/jon-portrait.jpg` | About snippet & About page — replace `PortraitPlaceholder` | `https://paradigmservices.ca/wp-content/uploads/.../paradigm-portrait-image-6.jpg` (confirm exact path with Jon) |
| `/public/og.jpg` (optional)     | Static fallback OG. Currently auto-generated by `src/app/opengraph-image.tsx` at the edge. | Replace only if you want a hand-designed social card.                                       |

## How to swap

1. Drop the binary into `public/images/`.
2. Open the component listed above and replace the `*Placeholder` JSX with a `next/image`:

   ```tsx
   import Image from "next/image";
   <Image
     src="/images/truck.png"
     alt="Paradigm branded service truck"
     fill
     priority
     sizes="(max-width: 1024px) 80vw, 480px"
     className="object-cover"
   />
   ```

3. Keep the `aspect-*` wrapper to avoid CLS.

Do **not** hotlink from `paradigmservices.ca` at runtime — download the asset locally so the new site is independent of WordPress.
